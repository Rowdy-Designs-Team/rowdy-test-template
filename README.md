# Rowdy Test Template - Dashboard Testing

🚀 **Live Testing Environment for Website Dashboard & Admin Portal**

This is a clean, minimal test template hosted on GitHub Pages for testing your dashboard and admin portal editing features.

## 📍 Live URLs

- **Main (Dark Mode):** https://rowdy-designs-team.github.io/rowdy-test-template/
- **Light Mode:** https://rowdy-designs-team.github.io/rowdy-test-template/light.html

## 🎯 Purpose

This template is designed to test:

- ✅ Content management system (CMS) updates
- ✅ Admin portal editing features
- ✅ Theme switching and styling changes
- ✅ Real-time content synchronization
- ✅ Dashboard functionality
- ✅ Live preview capabilities

## 📁 Files

- **index.html** - Main test page (dark theme)
- **light.html** - Light theme variation
- **README.md** - Documentation

## 🛠️ How to Use

### View Live
Simply visit the live URLs above to see the template in action.

### Local Development

```bash
# Clone the repo
git clone https://github.com/Rowdy-Designs-Team/rowdy-test-template.git

# Navigate to directory
cd rowdy-test-template

# Open in browser
open index.html  # or double-click the file
```

### Testing Dashboard Features

1. **Test Edit Feature** - Click the "Test Edit Feature" button to simulate dashboard editing
2. **Test Preview** - Click "Preview Changes" to test the preview mode
3. **Theme Switching** - Switch between light and dark modes
4. **Responsive Testing** - Resize browser window to test mobile/desktop

## 🎨 Customization

To modify the template for testing different features:

1. Edit `index.html` or `light.html`
2. Make changes and push to master branch
3. Changes auto-deploy to GitHub Pages (no configuration needed!)
4. Refresh the live URL to see updates
