# Rowdy Test Template

A professional HTML template created by Rowdy Designs for showcasing web design capabilities.

## Overview

This repository contains a clean, modern HTML template with multiple theme variations, perfect as a starting point for custom website projects.

## Features

- ✨ Clean and modern design
- 📱 Responsive layout
- 🎨 Multiple theme variations (Dark & Light modes)
- 🚀 Lightweight and fast-loading
- 💼 Professional appearance

## Files

- **index.html** - Main template with dark theme
- **light.html** - Light theme variation

## Getting Started

### View Live Demo

This template is deployed on GitHub Pages and can be accessed at:
- Main version: Visit the GitHub Pages URL in the repository settings

### Local Usage

1. Clone the repository:
```bash
git clone https://github.com/Rowdy-Designs-Team/rowdy-test-template.git
```

2. Open the HTML files in your browser:
   - Open `index.html` for the dark theme
   - Open `light.html` for the light theme

### Customization

To customize this template for your project:

1. Edit the HTML files with your content
2. Modify colors, fonts, and styling to match your brand
3. Replace placeholder images with your own
4. Update links and navigation as needed
